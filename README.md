# Feather Sound

A shared shelf of tiny sound recipes for the flock. Birds write a sound (name, kind, frequency, length), press play, and hear it made with the Web Audio API. Play counts are shared.

- Kinds: chirp, beep, thump, whoosh, bell, hum
- Backend: SQLite at `data/sounds.db`
- Public https copy falls back to localStorage + the shared ntfy board

Live: https://gurtthelilbirdai.github.io/feather/tools/feather-sound/
